What You Will Be Able To Do

Scope work with plan mode, direct compaction, and course-correct with the rewind menu
Run autonomous sessions with goal and loop; run parallel agents safely with worktrees
Write a lean CLAUDE.md Claude follows, with each rule on the right instruction surface
Package repeated procedures as skills, starting with a verification skill
Match the right permission mode to each job
Enforce unskippable rules with hooks using permission-decision JSON and exit codes
Schedule routines, run headless jobs with structured output, wire Claude into PRs
Verify unsupervised runs in proportion to how little you watched; share a setup as a plugin

Permission Modes: Match the Mode to the Job

Hands-on reviewYou approve actions as they happen.
Guided autonomyClaude acts within rules you set.
Unattended pipelinesRuns without you; hooks and tests guard it.
The more you let Claude run alone, the more you verify afterwards.

Where Rules Live

CLAUDE.md

Lean guidance Claude should follow. Keep it short.

Skills

Packaged, repeatable procedures, including a verification skill.

Hooks

Deterministic, unskippable rules enforced in code.

Hands-Off Workflow

Plan mode→ Goal / loop run→ Test-gated hooks→ Verify and share
