The Tool-Use Loop

Send request + tools→ stop_reason: tool_use→ Run tool→ Return tool_result↻
Repeat until the model returns end_turn. The API is stateless: resend the full history each call.

Workflows vs. Agents

Workflows

Predefined steps: chaining, routing, parallelization. Predictable and easier to test. Prefer when the steps are known.

Agents

Claude chooses steps and tools dynamically. Flexible for open-ended problems, but less predictable.
